    Class HealthLedger

    What was found, what was done about it, and how to undo it.

    The undo column is the part that matters more than the automation. Break-glass is the requirement: every automatic repair records what it did, is reversible, and bastion diagnose explains it. A repair nobody can reverse is a repair nobody should have run.

    Findings live in a file, because the process that finds them is not the process that reports them. serve detects; bastion health and bastion diagnose run later, from a different process, often after a restart. Held in memory this was a ledger created empty by each CLI invocation, read, and thrown away: every one of the 33 tripwires was unreachable by construction and nothing ever called record.

    A file rather than the management API for the reason the plan already gives for logs: a partitioned node has to stay diagnosable from itself, so reading its own health must need no credential and no network. Append-only and replayed on load, which is also what reconstructs the strike counts and quarantine timestamps a crash would otherwise lose.
