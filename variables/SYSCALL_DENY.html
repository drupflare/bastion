    Syscall groups a workerd tenant never needs.

    Expressed as systemd's SystemCallFilter sets rather than as a compiled BPF program, because that is the mechanism a Linux host already ships: no helper binary to build, no filter to keep in sync with a libc bump, and the same syntax on every distribution that runs systemd. A host without systemd-run cannot run hardened, and preflight refuses it by name rather than quietly running solo in its place.
