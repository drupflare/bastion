    Class BackupEngine

    The backup engine.

    Content-addressed: a frame whose digest the store already holds is not written again, which is what makes the second backup of a site cost its changed bytes rather than its size. The index is kept per site rather than globally so a prune can decide what is unreferenced without reading every other site's manifests.
