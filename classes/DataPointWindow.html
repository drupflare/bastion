    Class DataPointWindow

    A bounded ring of data points per tenant.

    Bounded because this is the exact shape that already cost this project a disk: miniflare's observability wrote every request into one unpruned file and reached 20.75 GB. A tenant looping on writeDataPoint fills a ring and evicts its own oldest rows rather than the host's free space.
