    Interface Capabilities

    What a driver's endpoint can do.

    Probed once per endpoint and cached. A probe that cannot run returns conservative defaults rather than optimistic ones, so an unknown endpoint degrades to more requests instead of to failed ones. The engine branches on the answer, never on a driver name.
