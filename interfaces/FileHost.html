    Interface FileHost

    The filesystem seam.

    Holds BYTES. readBytes / writeBytes exist because a site database and a workerd binary are not text, and the memory implementation stores Uint8Array rather than encoding on read -- so size() and readBytes().length agree for the same reason they agree on a real disk. A fixture that stored the string and encoded per call would read a binary member back as something else.
