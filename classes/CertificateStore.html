    Class CertificateStore

    Certificates on disk, one directory per host.

    The private key is written at 0600 before the certificate, and the pair is only advertised to the listener once both are there -- a half-written pair binds a listener with a key that does not match its chain, and every client sees a handshake failure rather than an error anyone can read.
