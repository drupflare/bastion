      Binds a replacement listener and drains the old one.

      Measured 2026-09-21, and this is not the obvious implementation. server.reload() does NOT re-read tls: a control proved the tls: [{...}] SNI array works when the server is born with it and does not change when reloaded into one. So a cert renewal or a new tenant hostname rebinds rather than reloading. reusePort: true lets both listeners hold the port at once, so there is no window where nothing is bound.
